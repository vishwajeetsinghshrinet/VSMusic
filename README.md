# VSMusic 🎵

VSMusic is a modern, mobile-first web music player built with HTML, CSS, and Vanilla JavaScript.

The goal of this project is to create a clean and lightweight music-player experience that works directly in a web browser and can eventually be installed as a Progressive Web App (PWA).

## Features

### Current
- Project foundation
- Responsive web architecture
- Vanilla JavaScript

### Planned
- Play local audio files
- Play / pause controls
- Previous / next track
- Seek/progress bar
- Volume control
- Playlist management
- Shuffle and repeat
- Favorites
- Search
- Album artwork
- Recently played
- Mobile-first interface
- PWA support
- Offline support
- Media Session / lock-screen controls

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio / HTMLAudioElement APIs
- Progressive Web App technologies

## Development

Clone the repository:

git clone https://github.com/YOUR_USERNAME/VSMusic.git

Enter the project:

cd VSMusic

Open the project in your preferred code editor.

For the basic version, the project can run directly in a modern web browser.

## Goal

Build a lightweight, beautiful and practical music player using web technologies while learning and improving JavaScript skills.
